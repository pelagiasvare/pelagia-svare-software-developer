# Agent Instructions

This is a TanStack Start (React) portfolio application deployed on Vercel.

## Conventions
- Server-only modules are named `*.server.ts` or marked with `@tanstack/react-start/server-only` (never import the Next.js `server-only` package).
- Keep commits on the main branch in a working state.
- Run `npm run lint` and `npm run format` before pushing.
